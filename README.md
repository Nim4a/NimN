# NiN

Personal fork of [PattN](https://github.com/patterniha/PattN), based on [v2rayN](https://github.com/2dust/v2rayN). Original copyright and GPL-3.0 license are retained.

## تغییرات نسخه شخصی

- نام نمایشی NiN و آیکون NI؛ رنگ کل آیکون سینی با حالت تغییر می‌کند: پاک‌کردن آبی، System Proxy قرمز، بدون تغییر بنفش، PAC سبز.
- نام فایل NimN.exe، نام ZIP و تگ‌های nimn برای سازگاری آپدیت حفظ شده‌اند.
- تصویر پرچم کنار نام کانفیگ در رابط‌های WPF و Avalonia؛ بدون وابستگی به نمایش ایموجی ویندوز.
- کشور ابتدا از نتیجهٔ تست IP خروجی استخراج می‌شود. برای کانفیگ‌های بدون نتیجهٔ تست، IP عمومی آدرس سرور به‌صورت خودکار و غیرهم‌زمان با HTTPS از ipwho.is مکان‌یابی می‌شود؛ این کشور ممکن است با خروجی واقعی اتصال (مثلاً پشت CDN) متفاوت باشد. در نبود نتیجه، برچسب نام فقط یک راهنمای تقریبی است؛ کشور نامشخص حدس زده نمی‌شود.
- حریم خصوصی: برای مکان‌یابی فقط IP عمومی به ipwho.is فرستاده می‌شود، نه نام، رمز یا متن کانفیگ. آدرس‌های محلی مکان‌یابی نمی‌شوند. نتیجه‌ها با محدودیت نرخ و کش موقت نگهداری می‌شوند؛ تغییر گروه یا فیلتر، بررسی فهرست قبلی را لغو می‌کند.

## دانلود و تست

[Releases](https://github.com/herbert-kara/NimN/releases) · [Build status](https://github.com/herbert-kara/NimN/actions/workflows/nimn-release.yml)

Workflow اختصاصی، تست‌ها و دو رابط ویندوز x64 را می‌سازد. تگ‌های `v*-nimn.*` فقط پس از موفقیت تست و هر دو بیلد منتشر می‌شوند. فایل‌ها امضای دیجیتال ندارند؛ SHA-256 کنار ZIP قرار می‌گیرد. بیلد موفق جایگزین تست اتصال روی دستگاه نیست.

## آپدیت خودکار از PattN

- [تسک همگام‌سازی](https://github.com/herbert-kara/NimN/actions/workflows/nimn-sync.yml) هر ۶ ساعت آخرین **انتشار پایدار** PattN را بررسی می‌کند؛ اجرا با تأخیر احتمالی GitHub است، نه بلافاصله پس از انتشار. اجرای دستی هم دارد. روی رایانهٔ شما تسکی لازم نیست.
- سورس انتشار جدید با تغییرات NimN ادغام می‌شود؛ آیکون‌های NI، نام NimN، مسیر آپدیت و اتصال نمایش پرچم با محافظ و تست بررسی می‌شوند. تداخل ادغام یا شکست تست/بیلد، انتشار را متوقف می‌کند و Issue می‌سازد؛ حل تداخل نیاز به بررسی انسانی دارد.
- هسته‌ها و داده‌های همراه از بستهٔ همان انتشار PattN گرفته می‌شوند، نه از نسخهٔ latest مستقل. فایل اجرایی اصلی PattN جایگزین NimN نمی‌شود.
- آپدیت داخل NimN فقط انتشار کامل NimN را می‌گیرد؛ کد PattN جدید قبلاً داخل آن ادغام شده است. نسخهٔ `v7.25.1-nimn.3` یا جدیدتر را نصب کنید؛ برای نسخهٔ قدیمی اگر آپدیت نمایش داده نشد، یک بار ZIP جدید را دستی بگیرید.
- فقط مخزن شخصی `herbert-kara/NimN` تغییر می‌کند. GitHub ممکن است زمان‌بندی مخزن عمومی کم‌فعالیت را پس از ۶۰ روز غیرفعال کند؛ در آن حالت workflow را دوباره فعال کنید.

## Upstream

PattN adds Iran-focused defaults and support for cipherSuites / unsafe fingerprints, with a modified Xray core. Original upstream documentation and donation details: [PattN README](https://github.com/patterniha/PattN#readme).
